## Usunięty film i własny player

Big Buck Bunny usunięto z aktywnego katalogu, playera i panelu źródeł. Własny player pozostał wyłącznie dla lokalnych plików użytkownika. Wybrany plik jest otwierany przez `URL.createObjectURL`, bez uploadu. Obsługiwane kodeki zależą od przeglądarki. VTT/SRT nie są pobierane z cudzych serwisów; użytkownik dodaje posiadane pliki. Nazwa pliku identyfikuje ścieżkę. Osobny dubbing wymaga osobnego pliku wideo; nie obiecujemy przełączania dowolnych wewnętrznych ścieżek MKV w HTML5.

## Zwiastuny zależne od sezonu i postęp lokalny

- Mapowanie w `seasonTrailers` nie przenosi zwiastuna na inny sezon. HB S2 zachowuje materiał Głośnego Zacisza. HB S3 (część 1): https://www.youtube.com/watch?v=qhE0XE__ZD0 — VOX record, 2:11, publikacja 28.09.2026; bezpośrednia strona potwierdziła polski tekst/obsadę i fanowski charakter. HB S1: nie potwierdzono polskiego zwiastuna tego sezonu, więc jest ukryty zamiast wyświetlania zwiastuna S2. Piloty/shorts bez pasującego materiału również nie pokazują odtwarzacza. Dla pojedynczego sezonu GLITCH zachowano istniejące zwiastuny. Strona startowa może prezentować zwiastun promocyjny serialu z jawnym podpisem sezonu.
- Pomiar odcinków YouTube korzysta z oficjalnego IFrame Player API (`https://www.youtube.com/iframe_api`, `enablejsapi=1`, `origin`). Co sekundę odczytuje czas i stan odtwarzania. Nie odczytuje zawartości obcego iframe przez DOM, nie obchodzi ograniczeń i nie mierzy Prime Video ani odtwarzania po otwarciu linku w YouTube. Zwiastuny nie są wliczane.
- Dane `rej-playback-v1` w localStorage: pozycja z ułamkiem sekundy, długość, łączny czas rzeczywistego odtwarzania, ukończenie, czas aktualizacji i nazwa. Oddzielne ID źródła dla oryginału i każdego fandubu zapobiegają przenoszeniu sekund między różnymi montażami. Dla YouTube parametr `start` ma pełne sekundy; po cue/play stosowana jest najwyżej jednorazowa korekta `seekTo`, tylko przy odchyleniu ponad 1,5 s (bez drugiego seekowania w onReady). Precyzję faktycznego startu ogranicza odtwarzacz/dekodowanie źródła. Nie uruchamiamy autoplay.
- Licznik nie dodaje samego otwarcia strony, pauzy, buforowania, dużych skoków przewijania ani przerw w próbkowaniu. Pokazuje czas oglądania (nie unikalne pokrycie filmu); ponowne obejrzenie zwiększa licznik. Przy przyspieszeniu liczymy czas zegarowy oglądania. Pomiar jest przybliżony: ograniczenie timerów w tle, nagłe zamknięcie procesu i blokady API mogą powodować braki. Przy normalnym wyjściu/pauzie zapisujemy końcową próbkę, przy awarii zwykle pozostaje ostatni zapis sekundowy.
- Pliki lokalne mają tożsamość nazwa + rozmiar + lastModified. Po ponownym wskazaniu tego samego pliku player wznawia pozycję po loadedmetadata. Nie zachowujemy dostępu do pliku, nie wznawiamy bez ponownego wskazania i nie przesyłamy jego treści. Nazwa pliku pozostaje tylko w przeglądarce. Zmieniony plik jest osobnym materiałem.
- Maksymalnie 500 zapisów; brak konta/synchronizacji. Wyczyszczenie danych witryny usuwa postęp. Zablokowana pamięć lokalna nie blokuje odtwarzania, lecz uniemożliwia trwały zapis. Zablokowane API YouTube zgłaszamy w UI zamiast generowania fikcyjnych statystyk.

## Aktualizacja napisów i ładowania odtwarzacza

Punkt odniesienia: https://developers.google.com/youtube/iframe_api_reference (zdarzenia gotowości, zmiany API i stanu; API nie gwarantuje wyboru audio ani pełnego wyboru języka napisów). `captions.track` / odczyt `languageCode` są próbą zgodności z embedami, nie gwarantowanym interfejsem dla każdej wersji YouTube. Brak odpowiedzi lub inny język nie oznacza potwierdzenia PL; podajemy instrukcję ręcznego wyboru napisów / tłumaczenia w YouTube. Nie pobieramy napisów ani nie obchodzimy izolacji iframe.

Testy obejmują symulowany odtwarzacz: opóźnione załadowanie modułu captions, odrzucenie preferencji PL, ograniczoną liczbę prób, zmianę napisów bez zmiany iframe/czasu, usuwanie playera i watchdogów, brak podwójnego seekowania oraz ręczne odzyskiwanie po błędzie. Te testy nie potwierdzają rzeczywistego dekodowania obrazu ani dostępności napisów na YouTube w regionie użytkownika.
